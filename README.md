# آکادمی قطعات الکترونیک | معلم خوب

وب‌اپلیکیشن آموزشی فارسی و راست‌چین برای شناخت خانواده‌های قطعات الکترونیک. نسخه فعلی شامل صفحه معرفی، دسته‌بندی خانواده قطعات، درس پایه مقاومت ثابت، نکات ایمنی اندازه‌گیری، آزمون کوتاه و ماشین‌حساب تعاملی کد رنگی مقاومت ۴ نواره است.

## اجرای محلی
فایل `index.html` را در مرورگر باز کنید. برای فونت فارسی، اتصال اینترنت جهت بارگذاری Google Fonts لازم است؛ خود محتوا بدون آن نیز قابل مشاهده است.

## انتشار با GitHub Pages
1. فایل‌های این پوشه را در ریشه مخزن قرار دهید؛ `index.html` باید مستقیماً در ریشه باشد.
2. در GitHub به **Settings → Pages** بروید.
3. در بخش Build and deployment، گزینه **Deploy from a branch** را انتخاب کنید.
4. شاخه `main` و پوشه `/(root)` را انتخاب و ذخیره کنید.
5. پس از پایان انتشار، سایت را با نشانی GitHub Pages مخزن باز کنید.

## نکات نسخه
- نشان SVG داخل `assets/` لوگوی موقت است و لوگوی رسمی گروه هنوز جایگزین نشده است.
- ماشین‌حساب کد رنگی فعلاً کد استاندارد مقاومت ۴ نواره را محاسبه می‌کند.
- درس‌های خانواده‌های دیگر به‌صورت مرحله‌ای توسعه داده می‌شوند.
- محتوای آموزشی باید متناسب با سطح هنرجو و دستورالعمل ایمنی کارگاه ارائه شود. اندازه‌گیری اهم فقط در مدار بی‌برق انجام شود.
