# آکادمی قطعات الکترونیک | معلم خوب
وب‌اپلیکیشن فارسی و واکنش‌گرا برای آموزش قطعات الکترونیک.

## انتشار با GitHub Pages
1. فایل‌های این پوشه را در ریشه مخزن GitHub بارگذاری کنید.
2. در مخزن به Settings → Pages بروید.
3. در Build and deployment گزینه Deploy from a branch را انتخاب کنید.
4. شاخه `main` و پوشه `/(root)` را انتخاب و Save کنید.

## امکانات نسخه اولیه
- صفحه خوش‌آمدگویی و معرفی مهندس مرتضی کرمی
- دسته‌بندی خانواده قطعات
- درس ابتدایی مقاومت ثابت و آزمون تعاملی
- ایمیل، کانال یوتیوب و تلگرام معلم خوب
- لوگوی SVG موقت در `assets/moallem-khoob-logo.svg`

## لوگو و تصاویر
لوگوی فعلی یک نشان موقت است، نه فایل لوگوی رسمی. تصاویر واقعی قطعات هنوز در این نسخه اضافه نشده‌اند؛ برای انتشار آموزشی حرفه‌ای باید تصاویر مجاز و باکیفیت هر قطعه و منابع/دیتاشیت معتبر به درس‌ها افزوده شوند.

## ایمنی
محتوا نمونه اولیه است. آموزش تست باید پیش از استفاده رسمی با دیتاشیت سازنده و منابع معتبر فنی بازبینی شود. تست مقاومت در حالت اهم باید در مدار بی‌برق انجام شود.
